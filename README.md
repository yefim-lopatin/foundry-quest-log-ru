# Квестовый журнал для Foundry VTT

Русскоязычный системно-независимый модуль для ведения квестов в Foundry Virtual Tabletop v14.

## Возможности

- отдельное окно мастера и игроков на `ApplicationV2`;
- категории, поиск и фильтры по статусу;
- активные, завершённые и проваленные квесты;
- обычные и секретные цели с отображением прогресса;
- квестодатель, место, описание, награды и закрытые заметки мастера;
- скрытие целого квеста от игроков;
- безопасная передача игрокам очищенного снимка без секретных целей и заметок мастера;
- публикация открытой карточки квеста в чат;
- хранение мастерских данных в штатных `JournalEntry` мира;
- системно-независимая работа: модуль не требует PF2e, D&D 5e или другой игровой системы.

## Совместимость

- Foundry VTT: **14.366**;
- минимальная версия: **14**;
- язык интерфейса: русский.

## Установка

После публикации релиза вставьте эту ссылку в поле **Установить модуль → URL манифеста**:

```text
https://github.com/yefim-lopatin/foundry-quest-log-ru/releases/latest/download/module.json
```

Также можно скачать `foundry-quest-log-ru.zip` из раздела Releases и распаковать папку `foundry-quest-log-ru` в `Data/modules`.

## Использование

1. Включите модуль в настройках мира.
2. Откройте журнал кнопкой в панели журналов, инструментом сцены или сочетанием `Shift+Q`.
3. Мастер нажимает **Новый квест**, заполняет карточку и выбирает видимость.
4. Игроки получают только открытые квесты и несекретные цели. Для получения данных в мире должен находиться активный мастер.
5. Кнопка сообщения публикует открытую карточку выбранного квеста в чат.

Мастерские `JournalEntry` намеренно закрыты от игроков. Модуль передаёт игрокам отдельный очищенный снимок, поэтому заметки мастера и секретные цели не попадают в клиентскую модель игрока.

## Проверка в Foundry

Рекомендуемый сценарий ручной проверки:

1. Создать чистый мир Foundry v14.366 и включить только этот модуль.
2. Создать квест с двумя целями, одну отметить секретной.
3. Открыть второй клиент под игроком и убедиться, что секретная цель и заметки мастера отсутствуют.
4. Скрыть весь квест и проверить, что он исчез у игрока.
5. Вернуть видимость, завершить квест и проверить статус и сообщение в чате.
6. Перезапустить мир и убедиться, что данные сохранились.

Перед испытанием в действующем мире сделайте резервную копию пользовательских данных Foundry.

## Разработка

Требуется Node.js 24 и системная утилита `zip`.

```bash
npm ci
npm test
npm run build
```

Готовые файлы появятся в `dist/`. Архив всегда содержит одну корневую папку `foundry-quest-log-ru`.

## Происхождение реализации

Код и визуальная система написаны с нуля. Другие квестовые модули использовались только как ориентир поведения. В репозитории нет кода, баз данных, изображений, аудио или иных материалов сторонних модулей.
